Teknikfag A | Digital Design og Udvikling  
Eksamensprojekt udviklet af Asger, Emilie og Kristine

---

## Features

### Stack

Godot 4.6 applikation udviklet for Android.

- Pokemon GO og GeoCaching inspireret
- Find waypoints i appen og udforsk dem i virkeligheden
- Real-time navigation
- Scan en QR kode for at udføre et waypoint
- Få point, digital reward, achivements

Node backend med bun.js

- Auth: koa.js med JWT (via jose)
- OSM vector scraping
- Server-side 3D map rendering
- Routing med BRouter API
- QR code generation
